A JavaScript DOM project for dynamic user management using forms and event handling.
# DOM User Management App

A simple JavaScript DOM project where users can:

- Add new users using a form
- Display user cards dynamically
- Prevent page refresh using form events
- Render UI from an array of objects
- Reset the form after submission

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation

## Concepts Practiced

- querySelector()
- Event Listeners
- Form Handling
- preventDefault()
- Arrays & Objects
- forEach()
- Dynamic UI Rendering
